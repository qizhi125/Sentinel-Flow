# 路线图

## 当前状态（v0.1.0）

已实现离线 pcap → JA3 → 告警 → SSE 垂直切片；实时抓包、规则引擎扩展、TLS
元数据与 eBPF 快路径尚未实现。

## 首个可用版本的验收标准

1. 10 MB 混合流量 pcap 在 15 秒内完成解析，展示流向与内置规则告警；
2. 干净机器上一条命令启动，30 秒内看到实时五元组；
3. 4 核 / 8 GB 机器、约 50 Mbps 负载下：CPU ≤ 50%、内存 ≤ 500 MB、
   2 小时稳定运行、丢包率 < 1%。

## 版本计划

| 系列 | 内容 | 出口标准 |
|------|------|----------|
| 0.1.x | 实时 pcap 抓包、Aho-Corasick/PCRE2 规则、TLS 元数据面板、权威 JA3 情报源 | 验收标准 1–2 端到端通过 |
| 0.2.x | aya-rs XDP + AF_XDP 快路径、性能对比、容器镜像 | eBPF 路径在更低 CPU 下与 pcap 结果一致 |
| 0.3.x | JA3S、熵与行为信号、流统计、预留 LLM 辅助接口 | 提交加密流量演示语料与基线数据 |
| 1.0 | 打包、部署文档、健康指标、发布说明 | 三条验收标准在干净硬件上全部通过 |

## 非目标与风险

- JA3 指纹在不同恶意家族间会重叠，命中只能作为待关联的信号，不能直接归因；
- XDP 支持因网卡驱动与内核版本而异，pcap/AF_PACKET 路径必须保留为兼容基线。
